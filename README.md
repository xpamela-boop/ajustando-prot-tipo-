# ⚡ Central do Protótipo

Este projeto é um protótipo interativo desenvolvido para testar novos fluxos de usabilidade, registro de tarefas e respostas em tempo real com feedback de microinterações.

## 🚀 Como Executar

1. Baixe ou clone este repositório.
2. Certifique-se de que os arquivos `index.html`, `style.css` e `script.js` estejam no mesmo diretório.
3. Abra o arquivo `index.html` em qualquer navegador.

## 📂 Estrutura do Projeto

```text
.
├── index.html   # Estrutura e marcação da aplicação
├── style.css    # Estilos, variáveis e animações

# 🚀 Protótipo do Projeto - Teste de Usabilidade

Este repositório contém a versão iterativa do protótipo da nossa aplicação, desenvolvida com base nos comentários e observações feitos durante os testes de usabilidade com usuários.

---

## 🎯 Sobre o Projeto

O objetivo do aplicativo é oferecer uma experiência simples, fluida e intuitiva para os usuários realizarem suas tarefas diárias de forma eficiente.

---

## 💡 Aprendizados com os Testes de Usuário

Após apresentar o protótipo e observar usuários interagindo com a interface, destacamos dois aprendizados fundamentais:

1. **Necessidade de Feedback Visual Imediato:** Observamos que o usuário precisa de confirmações visuais instantâneas após cada ação (ex: toasts de sucesso) para evitar dúvidas ou cliques duplos.
2. **Alta Intuitividade da Tela Principal:** O layout limpo permitiu que o usuário compreendesse e executasse a tarefa principal sem auxílio prévio.
